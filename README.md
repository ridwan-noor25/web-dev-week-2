
# SpendWise Dashboard

## Project Description

SpendWise is a responsive financial dashboard developed using HTML5 and CSS3. It provides a visual overview of personal finances, helping users monitor their budgets, expenses, savings and spending categories.

This project focuses on building a modern dashboard layout using CSS Grid and Flexbox.

## Project Files

### 1. index.html
Contains the structure of the SpendWise Dashboard, including:
- Sidebar navigation menu.
- Dashboard header and profile section.
- Financial overview with summary cards.
- Six expense category cards.
- Recent transactions table.
- Dashboard footer.

### 2. style.css
Controls the visual appearance and layout of the dashboard, including:
- CSS Grid for the overall dashboard layout.
- Flexbox for arranging sidebar, header and card contents.
- CSS custom properties for the colour theme.
- Google Fonts typography.
- Card styling using padding, borders and border-radius.
- Hover and keyboard focus animations.
- Responsive design using media queries.
- Dark theme using prefers-color-scheme.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Google Fonts (Poppins and Inter)

## Features

- Modern sidebar navigation.
- Financial summary cards.
- Six expense categories:
  - Food
  - Transport
  - Rent
  - Entertainment
  - Savings
  - Utilities
- Recent transactions table.
- Responsive dashboard layout.
- Interactive card hover and keyboard focus effects.
- Automatic dark theme support.
- Consistent green and cream colour palette.

## Design Identity

SpendWise uses a green and cream colour palette to create a clean, modern and professional financial dashboard.

### Colour Palette

- Primary Colour: Deep Green (#174C3C)
- Secondary Colour: Green (#26745C)
- Accent Colour: Gold (#D5A84F)
- Background: Soft Cream (#F4F7F2)
- Card Background: White (#FFFFFF)

### Typography

- Poppins for headings.
- Inter for body text and general content.

## Layout and Responsiveness

The dashboard uses CSS Grid for the main page structure and category cards. Flexbox is used to arrange the sidebar navigation, header content and individual card elements.

A media query adapts the dashboard into a single-column layout on screens narrower than 768px.
