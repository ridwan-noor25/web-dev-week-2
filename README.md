
# SpendWise Dashboard

## Project Description

SpendWise is a personal budgeting application developed using HTML, CSS and JavaScript. It provides a dashboard for viewing financial information and calculating remaining budgets.

## Project Files

### 1. index.html
Contains the dashboard structure, sidebar, financial summary cards, expense categories and transactions table.

### 2. style.css
Controls the dashboard appearance using CSS Grid, Flexbox, custom properties, responsive design and animations.

### 3. script.js
Contains the JavaScript logic responsible for:
- Declaring budget and expense variables.
- Collecting user input using prompt().
- Converting user input into numbers.
- Calculating the remaining balance.
- Displaying results in the browser console.
- Checking whether the budget has been exceeded.

## JavaScript Concepts Implemented

- Variables using let.
- Data types and numbers.
- User input using prompt().
- Type conversion using Number().
- Conditional statements using if and else.
- Arithmetic operations using subtraction.
- Reusable functions.
- Console output using console.log().

## Budget Calculation

The application calculates the remaining balance using:

Remaining Balance = Monthly Budget - Total Expenses
